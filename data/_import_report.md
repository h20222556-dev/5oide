# 오이데 스토리 데이터 변환 리포트 (Import Report)

이 파일은 `오이데_스토리_정리본.md`를 파싱하여 생성된 데이터 현황 및 원문의 확인 필요(⚠) 사항을 정리한 보고서입니다.
원문 대사는 지어내지 않고 충실히 보존하였으며, 확인이 필요한 사항은 임의로 메우지 않고 옵션/플래그 및 리포트로 분리했습니다.

## 1. 변환 요약 통계
- **총 장면 수**: 36개 (프롤로그, 장소 선택, 만남, 뱃길, 남이섬, 선착장 분기, 최종 선택 및 엔딩 5종 포함)
- **총 선택지 수**: 20개 (CHOICE 블록 기준)
- **지원 변수**: 
  - {player} (플레이어 입력 이름)
  - {닭갈비} (여: 다곡희 / 남: 다고길)
  - {양념} (여: 양연미 / 남: 양연우)
  - {고구마} (여: 고규미 / 남: 고구민)
  - {볶음밥} (여: 박복은 / 남: 박복검)

## 2. 원문 확인 필요(⚠) 및 임시 처리 목록

| 번호 | 항목 | 원문 상황 및 처리 방식 |
|---|---|---|
| 1 | **엔딩 장면이 없음.** | 최종 선택 이후 닭갈비, 양념, 고구마, 볶음밥, 혼자 돌아감의 엔딩 대사가 PDF에 없습니다. |
| 2 | **호감도 점수 숫자가 없음.** | 원문에는 "크게 / (등급 없음) ↑ / 소폭", "(+)" 표시, "변화 적음"만 있고, "점수는 새 체계가 정해지면 붙일게요"라는 메모가 있습니다. |
| 3 | **히든 조건.** | 원문은 "세 캐릭터가 모두 히든 기준에 닿았는지"입니다. 재회온도라는 수치는 PDF에 나오지 않습니다. 프롤로그에도 헤어지는 장면은 없고, 목소리 회상만 있습니다. |
| 4 | **후반부가 초안 상태.** | 선착장 장면 이후에 "장면 2 (초안)", "장소 배정 (제안)", "돌아가는 길 (구조 초안)" 같은 표기가 붙어 있어 확정본인지 확인이 필요합니다. |
| 5 | **Day 1 반복 구조.** | #4, #5가 "#3 내용 반복"으로만 적혀 있어, 메시지 장면과 다음 장소 선택이 어디까지 반복되는지 확인이 필요합니다. |
| 6 | **Day 2 선택.** | Day 1처럼 세 명을 순차적으로 모두 만나는 구조(첫 선택 3명 중 1명 -> 두 번째 선택 남은 2명 중 1명 -> 마지막 1명 -> s08 마무리)로 확정 적용함. |
| 7 | **판정 시점.** | 승선 직전 판정 메모와, 하선 시점으로 옮기자는 메모가 둘 다 있습니다. 이 정리본에서는 하선 시점 판정을 기준으로 보는 것을 권합니다. |
| 8 | **선택지와 효과의 짝이 불확실한 곳.** | s09(주인공의 반응), s11_dakgalbi, s11_goguma, s11_yangnyeom의 3번째 보기, s12 전체의 효과 열은 원문 표가 뒤섞여 있어 배열 순서대로 옮겼습니다. |
| 9 | **"그것도... 잘" (고구마, Day 2 카페).** | 뒤에 "모르겠어요" 같은 말이 빠진 것으로 보입니다. |
| 10 | **#7 중복.** | "#7 Day2" 제목의 블록이 두 번 나오고, 첫 번째는 Day 1 마무리와 같은 내용입니다. |
| 11 | **혼자 돌아간다의 나레이션 위치.** | 최종 선택 표 끝에 붙은 "남이섬. 가평을 거치지 않고도..." 나레이션의 위치가 확실하지 않습니다. |
| 12 | **복원한 숫자.** | 숫자가 사라져 있던 곳을 문맥으로 복원했습니다: 2035년, 아침 9시, 약 40분, 환승 0번, 가평 경유 0번. |
| 13 | **수정한 오타.** | 여류롭게→여유롭게, 앙념→양념, 공지천ㅊ럼→공지천처럼, 저 자시에게→저 자신에게, 말처러→말처럼, 건내→건네, 참에 빠져든다→잠에 빠져든다. |
